# PlacementHub

To run the environment with docker desktop:

```powershell
docker compose up -d
npm run dev
```

## Test accounts

- Admin — `admin@placement.com` / `admin123`
- Officer — `officer@placement.com` / `officer123`
- Students / Recruiters — sign up via the `/signup` page

## Notes

- Students MUST fill their profile (CGPA etc.) before applying — eligibility is checked against it.
- Resume upload (PDF only) is required before applying to any job.
- Recruiters must belong to the company to post jobs for it.
